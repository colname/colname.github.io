# YJUN 羽毛球管理工具

面向手机使用的单场地羽毛球 PWA，包含双打公平排赛、四人单打轮转、21分计分、比赛计时、排名、历史记录和结果图片分享。

## 功能

- 首页可在“双打”和“单打”两个独立排赛页面间切换
- 双打支持 6–8 人的男女组合排赛
- 每场 4 人，严格保证每人比赛次数一致
- 按顺序优化搭档重复、对手重复和连续出场
- 男双、女双、混双仅与相同类型队伍对阵
- 单打固定4人单循环，共6场，每人3场，每两人交手一次
- 21分制计分，支持 10/15/18/21 快捷比分
- 按胜场和净胜分计算个人排名
- 多活动历史、本地保存、旧版记录迁移
- CSV 复制、PNG 结果图和系统分享
- PWA 安装及离线访问

## 本地运行

该项目使用原生 ES Modules，需要通过本地 HTTP 服务打开：

```bash
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 测试

安装 Node.js 后运行：

```bash
npm test
```

测试覆盖排赛可行性、合法比赛结构、绝对公平约束和排名规则。

## 数据说明

数据只保存在当前浏览器的 `localStorage`。新版首次打开时会复制迁移
`yjun_badminton_iphone_v1` 中的旧版14轮记录，但不会删除旧数据键。
